Entry for the make.fun competition "Funniest Time Machine Warning Label" ($2, winner-takes-all).

`main.ts` writes a single warning label of at most 120 characters to `/output/entry.txt`:

> WARNING: Do not kill your grandfather. He has an excellent lawyer, and you have not been born yet.

Run it with `node --experimental-strip-types main.ts` (or set `MAKEFUN_OUTPUT_DIR` to choose the output folder).
